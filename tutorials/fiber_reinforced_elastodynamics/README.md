# Fiber-reinforced elastodynamics input

`parameters.prm.in` configures the 2D matrix/embedded-line example documented
in `doc/tutorials/fiber-reinforced-elastodynamics.md`. It uses independent
distributed matrix and 1D fiber FE spaces and a vector multiplier field. CMake
writes the runtime file to
`build/tutorials/fiber_reinforced_elastodynamics/parameters.prm`.
